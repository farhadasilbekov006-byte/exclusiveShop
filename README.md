# 🛒 E-Commerce Backend API

Backend для интернет-магазина, разработанный на **Node.js**, **Express / NestJS**, **TypeScript** и **MongoDB**.  
Проект включает авторизацию, управление товарами и корзину.

---

## 🚀 Технологии

- Node.js
- Express.js / NestJS
- TypeScript
- MongoDB + Mongoose
- JWT (авторизация)
- bcrypt (хеширование пароля)
- dotenv
